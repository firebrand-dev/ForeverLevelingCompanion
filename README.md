# Forever Leveling Companion (FLC)

**Español** · [English](#english)

Guía de subida de nivel gratuita para **WoW: Forever**: flecha, seguimiento de misiones y Modo Grupo para subir con
amigos.

- **Descarga:** [Releases](https://github.com/firebrand-dev/ForeverLevelingCompanion/releases/latest), el archivo
  `FLC-<versión>.zip`.
- **Instalación:** [INSTALL.txt](INSTALL.txt). Copiá las dos carpetas, `ForeverLevelingCompanion` y
  `FLC_Guides_Catalog`, a `World of Warcraft\_forever_\Interface\AddOns`.
- **Web:** https://firebrand-dev.github.io/ForeverLevelingCompanion/
- **Reportar un problema:** en el juego escribí `/flc bug` o `/flc review` y pegalo en
  [FLC-reportes](https://github.com/firebrand-dev/FLC-reportes).
- **Cambios:** [CHANGES.md](CHANGES.md).

## English

A free leveling guide for **WoW: Forever**: an arrow, a quest tracker and a Party Mode to level with friends.

- **Download:** [Releases](https://github.com/firebrand-dev/ForeverLevelingCompanion/releases/latest), the
  `FLC-<version>.zip` file.
- **Install:** [INSTALL.txt](INSTALL.txt). Copy both folders, `ForeverLevelingCompanion` and `FLC_Guides_Catalog`,
  into `World of Warcraft\_forever_\Interface\AddOns`.
- **Website:** https://firebrand-dev.github.io/ForeverLevelingCompanion/
- **Report a problem:** in the game type `/flc bug` or `/flc review` and paste it at
  [FLC-reportes](https://github.com/firebrand-dev/FLC-reportes).
- **Changes:** [CHANGES.md](CHANGES.md).
